New Hire Onboarding Checklist

Note: Please use this page to notify your manager/admin by filling out the form for each task as they are completed.

We recommend you keep your own list of tasks/progress, as progress on this page will refresh.

Onboarding/Licensing

Task Notes Completed

Study Course Completed

Passed State Licensing Exam

After passing the exam you usually recieve info with your exam results regarding when you can apply for the license.
It typically includes instructions on how to apply for the license as well.
You will have to wait 2-3 business days before you can apply for the license.
Follow the instructions that were provided with your results.

Applied for State License

License approval can take 7-10 business days to be approved.
Typically 2-3 business days is standard.

Agent Resources Document is Shared

New agent bootcamp Completion, Script Review etc.
(Each agent should be fully familar with the information on this doc. This should happen while waiting for license approval)

Void Check & Direct Deposit Form
Obtained by Agent

This step should happen while waiting on license to be approved

State License Approved

Get E&O Coverage; must have this to start contracting.

NIPR Licensing

After recieving license approval agents need to ensure that the state's data has synced to NIPR.
NIPR is basically a database for all of your licensing information.
Use this link to check if your information has been synced: https://nipr.com/help/look-up-your-npn
You will know that your license info has been synced if your NPN, Name, etc. shows up.
Once you have this info on NIPR, please send a screenshot of the page that includes NPN etc. to Allie
